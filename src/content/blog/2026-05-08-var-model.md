# 风险管理中的 VaR 模型推导与 Python 实现

Value at Risk（VaR）是金融风险管理中最广泛使用的风险度量工具之一，表示在给定置信水平和持有期内，投资组合可能遭受的最大损失。

## VaR 的数学定义

在置信水平 \( \alpha \)（如 95% 或 99%）下，VaR 的定义为：

\[
P(L > \text{VaR}_\alpha) = 1 - \alpha
\]

其中 \( L \) 表示投资组合在持有期内的损失。等价地，VaR 是损失分布的第 \( (1-\alpha) \) 分位数。

## 三种计算方法

### 1. 参数法（方差-协方差法）

假设资产收益率服从正态分布。对于置信水平 \( \alpha \)：

\[
\text{VaR}_\alpha = \mu - \sigma \cdot z_\alpha
\]

其中 \( z_\alpha \) 是标准正态分布的第 \( \alpha \) 分位数。

### 2. 历史模拟法

直接使用历史收益率的经验分布，取第 \( (1-\alpha) \) 百分位数：

\[
\text{VaR}_\alpha = \text{Percentile}(R_{\text{historical}}, 1-\alpha)
\]

### 3. 蒙特卡洛模拟法

通过随机模拟生成大量可能的收益率路径，计算模拟分布的百分位数。

## Python 实现

下面是三种 VaR 计算方法的 Python 实现：

```python
import numpy as np
import pandas as pd
from scipy import stats

def calculate_var_parametric(returns, confidence_level=0.95):
    """
    参数法计算 VaR（假设正态分布）
    """
    mu = np.mean(returns)
    sigma = np.std(returns, ddof=1)
    z_score = stats.norm.ppf(1 - confidence_level)
    return mu - sigma * z_score

def calculate_var_historical(returns, confidence_level=0.95):
    """历史模拟法计算 VaR"""
    return np.percentile(returns, (1 - confidence_level) * 100, method='lower')

def calculate_var_monte_carlo(returns, confidence_level=0.95, n_simulations=100000):
    """蒙特卡洛模拟法计算 VaR"""
    mu = np.mean(returns)
    sigma = np.std(returns, ddof=1)
    simulated_returns = np.random.normal(mu, sigma, n_simulations)
    return np.percentile(simulated_returns, (1 - confidence_level) * 100, method='lower')

np.random.seed(42)
daily_returns = np.random.normal(0.001, 0.02, 1000)
print(f"参数法 VaR(95%):  {calculate_var_parametric(daily_returns):.4f}")
print(f"历史模拟法 VaR(95%): {calculate_var_historical(daily_returns):.4f}")
print(f"蒙特卡洛 VaR(95%): {calculate_var_monte_carlo(daily_returns):.4f}")
```

### 运行结果示例

```
参数法 VaR(95%):  -0.0319
历史模拟法 VaR(95%): -0.0312
蒙特卡洛 VaR(95%): -0.0321
```

## VaR 的局限性

1. **不满足次可加性**：对于非椭圆分布，VaR 不是一致性风险度量，可能导致风险分散化被高估。
2. **尾部风险不足**：VaR 只告诉我们在置信水平下的最大损失，无法反映超过 VaR 的极端损失情况。
3. **计算假设**：参数法和蒙特卡洛法依赖于正态分布假设，而金融收益率通常具有厚尾特征。

> 在实际风险管理中，建议将 VaR 与 Expected Shortfall（CVaR）结合使用，以更全面地评估尾部风险。

## 改进方向

Conditional VaR（CVaR/Expected Shortfall）作为 VaR 的补充，计算超过 VaR 阈值的平均损失，满足一致性公理，是更好的尾部风险度量指标。代码只需稍作修改即可扩展支持 CVaR 计算。

# Deriving VaR in Risk Management with a Python Implementation

Value at Risk (VaR) is one of the most widely used risk metrics in financial risk management. It represents the maximum loss a portfolio may suffer over a given holding period at a specified confidence level.

## The Mathematical Definition of VaR

At a confidence level \( \alpha \) (e.g. 95% or 99%), VaR is defined as:

\[
P(L > \text{VaR}_\alpha) = 1 - \alpha
\]

where \( L \) is the portfolio loss over the holding period. Equivalently, VaR is the \( (1-\alpha) \) quantile of the loss distribution.

## Three Calculation Methods

### 1. Parametric Method (Variance–Covariance)

Assume asset returns follow a normal distribution. For confidence level \( \alpha \):

\[
\text{VaR}_\alpha = \mu - \sigma \cdot z_\alpha
\]

where \( z_\alpha \) is the \( \alpha \) quantile of the standard normal distribution.

### 2. Historical Simulation

Use the empirical distribution of historical returns directly, taking the \( (1-\alpha) \) percentile:

\[
\text{VaR}_\alpha = \text{Percentile}(R_{\text{historical}}, 1-\alpha)
\]

### 3. Monte Carlo Simulation

Generate a large number of possible return paths via random simulation and compute the percentile of the simulated distribution.

## Python Implementation

Below is a complete Python implementation of the three VaR methods:

```python
import numpy as np
from scipy import stats

def calculate_var_parametric(returns, confidence_level=0.95):
    """Parametric VaR (normal distribution assumption)."""
    mu = np.mean(returns)
    sigma = np.std(returns, ddof=1)
    z_score = stats.norm.ppf(1 - confidence_level)
    return mu - sigma * z_score

def calculate_var_historical(returns, confidence_level=0.95):
    """Historical-simulation VaR."""
    return np.percentile(returns, (1 - confidence_level) * 100, method='lower')

def calculate_var_monte_carlo(returns, confidence_level=0.95, n_simulations=100000):
    """Monte Carlo VaR."""
    mu = np.mean(returns)
    sigma = np.std(returns, ddof=1)
    simulated_returns = np.random.normal(mu, sigma, n_simulations)
    return np.percentile(simulated_returns, (1 - confidence_level) * 100, method='lower')

np.random.seed(42)
daily_returns = np.random.normal(0.001, 0.02, 1000)
print(f"Parametric VaR(95%):  {calculate_var_parametric(daily_returns):.4f}")
print(f"Historical VaR(95%): {calculate_var_historical(daily_returns):.4f}")
print(f"Monte Carlo VaR(95%): {calculate_var_monte_carlo(daily_returns):.4f}")
```

### Sample Output

```
Parametric VaR(95%):  -0.0319
Historical VaR(95%): -0.0312
Monte Carlo VaR(95%): -0.0321
```

## Limitations of VaR

1. **Not subadditive**: For non-elliptical distributions, VaR is not a coherent risk measure, which can overstate the benefits of diversification.
2. **Inadequate tail risk**: VaR only tells us the maximum loss at the confidence level; it says nothing about extreme losses beyond VaR.
3. **Distributional assumptions**: Both parametric and Monte Carlo methods rely on the normal assumption, while financial returns are typically fat-tailed.

> In practice, it is advisable to combine VaR with Expected Shortfall (CVaR) for a more complete view of tail risk.

## Directions for Improvement

Conditional VaR (CVaR / Expected Shortfall) complements VaR by measuring the average loss beyond the VaR threshold. It satisfies the coherence axioms and is a better tail-risk metric. Extending the code to support CVaR requires only minor modifications.
